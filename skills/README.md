# Claude skills

Skills are folders of instructions that teach Claude a full workflow. Drop one in and Claude follows it step by step, every time.

## Free: KreaSite

**Show Claude a website that impresses you (screen recording, screenshot or link). It rebuilds one at the same level, in your brand and for your project.** Three.js, WebGL, scroll-driven camera, motion. It copies the technique and the feeling, never the texts, logos or assets of the reference.

What it does, in order: analyze the reference → collect your project and brand → transpose → build → test in a headless browser → deliver.

→ [`kreasite/SKILL.md`](kreasite/SKILL.md)

### Install

- **Claude Code**: copy the `kreasite` folder into `~/.claude/skills/`.
- **Claude app**: zip the `kreasite` folder and add it as a custom skill.

Then just say: *"Here's a site I love, rebuild it for my brand."*
